# BeEmoji

**把照片里的真实物品，变成保留原有特征的 Emoji。**

BeEmoji 是一款 AI 图片编辑工具。上传照片、选择其中一个物品，BeEmoji 会保留它的轮廓、姿态、颜色和标志性细节，将其转化为柔和的 Emoji 风格，并放回原图中的对应位置。

> 在线体验：即将上线

## 可以做什么

- 在一张照片中识别多个可编辑主体。
- 通过涂抹快速指定想要处理的物品。
- 手动增加或擦除选区，修正主体边缘。
- 保留主体的姿态、视角、颜色分区和关键装饰。
- 生成透明背景的 Emoji 风格图片。
- 将生成结果放回原位置，尽量匹配原图的光线与色温。
- 撤回替换、继续选择其他主体并下载最终图片。

## 使用方式

1. 上传一张包含清晰物品的照片。
2. 使用涂抹工具标记想要转换的主体。
3. 检查识别轮廓，必要时增加或擦除选区。
4. 点击生成，等待 BeEmoji 完成风格化和原位替换。
5. 继续编辑其他主体，或者下载最终图片。

普通用户不需要准备或填写任何 API Key。图片识别、分割和生成能力均由 BeEmoji 的服务端统一提供。

## 风格原则

BeEmoji 不把所有物品变成同一个通用卡通形象。生成结果优先保留：

- 原主体的类别和完整轮廓；
- 姿态、朝向、观察角度和比例；
- 主色、辅色及颜色区域的位置；
- 已有五官、装饰和具有辨识度的细节；
- 原照片中的光线方向、色温和明暗关系。

风格表现采用柔和半立体、低光泽、连续渐变和轻微内阴影，避免明显色块、过度饱和和塑料玩具质感。

## 隐私说明

- 用户图片只用于完成当前编辑任务。
- 图片会发送至所需的第三方 AI 服务进行识别、抠图或生成处理。
- 正式服务将对任务图片设置自动过期时间，默认在 24 小时后删除。
- API Key 仅保存在服务端，不会发送到用户浏览器，也不会提交到公开代码仓库。

请不要上传包含身份证件、金融信息或其他高度敏感内容的图片。

## 当前阶段

BeEmoji 目前处于 MVP 验证阶段，优先支持甜品、饮品、玩偶和常见静物。人物、复杂遮挡、透明物体和大规模多人场景暂不作为首轮重点。

## 技术概览

- 前端：React、TypeScript、Vite
- 后端：Python、FastAPI
- 主体分割：MobileSAM
- 图像处理：OpenCV、Pillow
- 云端能力：百度智能云、阿里云百炼
- 部署目标：阿里云函数计算、OSS、ACR

## 项目状态

当前重点：

- 提升涂抹分割的完整性和稳定性；
- 提升生成结果与原主体的颜色、结构一致性；
- 控制整体处理时间在 60 秒以内；
- 完成面向小规模用户验证的云端部署。
